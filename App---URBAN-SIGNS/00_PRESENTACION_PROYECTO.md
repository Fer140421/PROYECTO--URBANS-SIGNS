# GEORESCUE 360 · EJEMPLO DE TRABAJO FINAL NIVEL PRO

## Problema demostrativo

Registrar incidencias sin ubicación exacta, evidencia visual ni trazabilidad dificulta priorizar, verificar y dar seguimiento.

## Propuesta

Una app móvil Flutter que permite autenticarse, registrar una incidencia con GPS y foto, enriquecerla con una API externa, persistirla en PostgreSQL, visualizarla sobre un mapa y controlar el acceso con RLS.

## Módulos

1. Auth y perfiles.
2. Dashboard y métricas.
3. CRUD de incidencias.
4. GPS.
5. Cámara/galería.
6. Storage.
7. Mapa.
8. API clima.
9. Seguridad RLS.
10. Preferencias locales.
11. Pruebas.
12. Git / build / defensa.

## Por qué vale como ejemplo

No intenta impresionar con funciones desconectadas. Cada tecnología resuelve una necesidad concreta del problema.
