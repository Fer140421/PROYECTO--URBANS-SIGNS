# Demo épica en 8 minutos

## Minuto 0-1 · Login

Explica que DEMO permite explorar sin backend y LIVE activa Supabase.

## Minuto 1-2 · Dashboard

Muestra métricas: total, abiertos, críticos, resueltos.

## Minuto 2-4 · Nuevo reporte

- título
- categoría
- severidad
- GPS
- mapa
- clima vía Open-Meteo
- fotografía

## Minuto 4-5 · Persistencia

En LIVE, guarda y abre Supabase Table Editor. Muestra la fila real.

## Minuto 5-6 · Mapa

Muestra los marcadores geográficos y abre el detalle.

## Minuto 6-7 · Seguridad

Explica RLS: todos pueden ver el mapa comunitario, sólo dueño/admin puede modificar.

## Minuto 7-8 · Ingeniería

Muestra Git, README, tests y APK.

Frase de cierre:

> No es una pantalla bonita conectada a una tabla. Es una solución que integra dispositivo, servicios, seguridad, datos, evidencia y distribución.
