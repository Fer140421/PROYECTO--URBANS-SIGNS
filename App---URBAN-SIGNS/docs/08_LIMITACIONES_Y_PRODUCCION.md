# Qué faltaría para producción real

Este proyecto es avanzado para un diplomado, pero una producción real puede requerir además:

- observabilidad y Crashlytics/Sentry;
- rate limiting / captcha en registro;
- moderación de reportes;
- compresión y borrado de imágenes huérfanas;
- políticas de privacidad y consentimiento de ubicación;
- auditoría administrativa;
- notificaciones push;
- estrategia offline-first;
- pruebas de integración/E2E;
- CI/CD;
- accesibilidad auditada;
- backups y recuperación;
- monitoreo de costos y límites de servicios;
- canales oficiales de escalamiento de emergencias.

La aplicación no debe presentarse como un servicio oficial de emergencias sin respaldo institucional.
