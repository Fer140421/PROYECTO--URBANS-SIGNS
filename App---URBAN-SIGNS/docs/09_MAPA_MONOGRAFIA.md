# Cómo GeoRescue 360 se convierte en monografía

## Capítulo 1

- Antecedentes: sistemas de reporte ciudadano / incidencias.
- Problema: falta de trazabilidad, georreferencia o evidencia.
- Justificación: app móvil + backend online.
- Objetivo general: desarrollar una solución móvil para registrar y gestionar incidencias georreferenciadas.
- Objetivos específicos: requisitos, arquitectura, CRUD, GPS/cámara/API, seguridad, pruebas y despliegue.

## Capítulo 2

- Fundamentos: Flutter, cliente-servidor, REST, persistencia, GPS, mapas.
- Metodología: sprints / Kanban / Scrum.
- Requisitos: usuario y administrador.
- Arquitectura: Flutter → Supabase / Open-Meteo / OSM / GPS.
- Datos: `profiles` + `incidents`.
- Implementación: flujo de reporte.
- Seguridad: Auth + RLS + secretos por configuración.
- Pruebas: usar `docs/05_PRUEBAS_Y_DEFENSA.md`.
- Despliegue: APK/AAB.

## Capítulo 3

Conclusiones vinculadas uno a uno con los objetivos verificables.
